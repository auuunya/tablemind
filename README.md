### 这个工具是做什么的？

TableMind数据对比工作台是一个帮助您快速发现多个Excel文件之间数据差异的工具。无需编程知识，只需简单几步，即可完成数据对比任务。

**适用人群：**
- 营销人员：对比不同时期或渠道的销售数据
- 仓储管理员：核对入库单、出库单与库存表
- 店长：比较门店商品价格和库存数据
- 任何需要对比Excel数据的人员

**核心优势：**
- ✅ 无需编程基础，操作简单直观
- ✅ 所有处理在本地完成，数据绝对安全
- ✅ 自动识别差异并生成报告
- ✅ 支持多文件同时对比
- ✅ 可导出详细对比报告

### 5步完成对比

1. **上传文件** - 拖拽或点击上传2个或更多Excel文件
2. **选择工作表** - 如果有多个Sheet，选择要对比的具体表格
3. **创建对比组** - 匹配不同文件中的列名
4. **配置规则** - 选择匹配键和对比字段
5. **查看结果** - 自动生成对比报告，支持筛选和导出

## 📝 详细操作指南

### 步骤1：上传Excel文件

1. 进入工具主页，您会看到一个上传区域
2. **方法一**：直接拖拽Excel文件到上传区域
3. **方法二**：点击上传区域，在弹出的对话框中选择文件

**注意事项：**
- 至少上传2个文件才能进行对比
- 单个文件建议不超过20MB
- 只支持 `.xlsx` 和 `.xls` 格式
- 系统会自动验证文件格式和大小

**提示：** 上传后会显示文件列表，包含文件名、大小和工作表数量。

### 步骤2：选择工作表（如果需要）

如果您的Excel文件包含多个Sheet（工作表），需要选择要对比的具体表格：

1. 在文件列表中找到对应的文件
2. 点击"工作表"下拉菜单
3. 选择要使用的Sheet
4. 系统会显示该Sheet的行数和列数

**提示：** 默认会选择第一个工作表。

### 步骤3：创建对比组并匹配列名

#### 什么是对比组？

对比组是一个对比任务的配置单元，包含：
- 要对比的文件列表
- 列名映射关系
- 对比规则

#### 如何创建对比组？

1. 点击"添加对比组"按钮
2. 给对比组起一个有意义的名字（如"本周与上周销售对比"）
3. 选择要对比的文件（至少2个）
4. 配置列映射

#### 什么是列映射？

不同的Excel文件可能对相同数据使用不同的列名。例如：
- 文件A：`商品名称`
- 文件B：`产品`

虽然名字不同，但表示的是同一种数据。列映射就是告诉系统"这两列是一样的"。

#### 如何配置列映射？

1. 点击"添加字段映射"
2. 输入统一的**目标字段名**（如"商品名称"）
3. 为每个文件选择对应的**源列名**：
   - 文件A选择"商品名称"
   - 文件B选择"产品"
4. 重复以上步骤，映射所有需要对比的列

**提示：** 系统会尽可能自动匹配相似的列名。

### 步骤4：配置对比规则

配置对比规则是最关键的一步，决定了如何匹配和对比数据。

#### 选择唯一匹配键（Primary Key）

**什么是匹配键？**

匹配键就像每条记录的"身份证"，用于在不同文件中找到同一条记录。

**常见的匹配键：**
- 订单号
- 商品ID / SKU
- 员工工号
- 日期 + 商品组合
- 门店 + 日期

**如何选择？**

1. 在"唯一匹配键"区域
2. 勾选一个或多个字段作为匹配键
3. 确保这些字段的组合在每个文件中都是唯一的

**示例：**
- 如果对比商品数据，选择"商品ID"
- 如果对比每日每店的销售，选择"日期"+"门店"

#### 选择对比字段

**什么是对比字段？**

对比字段是需要检查是否一致的数据列。

**常见的对比字段：**
- 价格
- 数量
- 库存
- 状态
- 金额

**如何选择？**

1. 在"需要对比的字段"区域
2. 勾选您想要对比的字段
3. 不需要对比的字段可以不选

**注意：** 匹配键不能同时作为对比字段。

### 步骤5：开始对比并查看结果

#### 开始对比

配置好规则后：
1. 点击页面底部的"开始对比"按钮
2. 系统会自动处理数据（通常几秒内完成）
3. 跳转到结果页面

#### 查看统计仪表板

结果页面顶部会显示统计卡片：
- **总记录数**：对比的总行数
- **完全匹配**：所有字段都一致的记录数
- **存在差异**：有字段不同的记录数
- **数据缺失**：只在部分文件中存在的记录数

还会显示：
- 数据一致性百分比
- 字段差异分布（哪个字段差异最多）
- 数据质量总结和建议

#### 筛选结果

使用顶部的筛选按钮：
- **全部**：查看所有记录
- **差异**：只查看有差异的记录
- **缺失**：只查看缺失的记录

#### 理解结果表格

表格列说明：
1. **状态列**：显示每行的对比状态
   - 绿色"匹配"：完全一致
   - 黄色"差异"：部分字段不同
   - 红色"缺失"：在某些文件中不存在

2. **数据列**：显示匹配键和其他字段的值

3. **差异详情列**：对于有差异的字段，显示每个文件中的具体值
   - 用不同颜色的小圆点标识文件
   - 清楚显示每个文件中的不同值

#### 导出报告

1. 点击右上角的"导出报告"按钮
2. 选择导出选项：
   - 是否包含状态列
   - 导出全部还是当前筛选结果
3. 系统会下载一个Excel文件
4. 文件命名格式：`对比报告_[对比组名称].xlsx`

**提示：** 导出的报告包含所有差异详情，方便后续分析和存档。

## 💼 常见场景示例

### 场景1：对比本周和上周销售数据

**背景：** 您需要对比本周和上周的商品销售情况，找出销量变化。

**步骤：**

1. 上传两个文件：
   - `本周销售.xlsx`
   - `上周销售.xlsx`

2. 创建对比组："本周VS上周销售"

3. 列映射：
   ```
   商品ID: [本周]商品ID → [上周]商品ID
   商品名称: [本周]商品名称 → [上周]商品名称
   销售数量: [本周]销量 → [上周]销量
   销售金额: [本周]金额 → [上周]金额
   ```

4. 配置规则：
   - 匹配键：`商品ID`
   - 对比字段：`销售数量`, `销售金额`

5. 查看结果：
   - 差异：销量或金额变化的商品
   - 缺失：本周新增或停售的商品

### 场景2：核对供应商发货单和实际收货单

**背景：** 仓库收货后，需要核对供应商的发货清单和实际收到的货物是否一致。

**步骤：**

1. 上传两个文件：
   - `供应商发货单.xlsx`
   - `实际收货单.xlsx`

2. 创建对比组："发货vs收货"

3. 列映射：
   ```
   商品编码: [发货]商品编码 → [收货]商品编码
   商品名称: [发货]品名 → [收货]品名
   发货数量: [发货]数量 → [收货]数量
   ```

4. 配置规则：
   - 匹配键：`商品编码`
   - 对比字段：`发货数量`

5. 查看结果：
   - 差异：数量不符的商品（可能少发或多发）
   - 缺失：发了但没收到，或收到但未在发货单上

### 场景3：检查库存盘点表和系统库存表

**背景：** 实际盘点后，需要对比实际库存和系统库存。

**步骤：**

1. 上传两个文件：
   - `实际盘点.xlsx`
   - `系统库存.xlsx`

2. 创建对比组："盘点vs系统"

3. 列映射：
   ```
   商品ID: [盘点]商品ID → [系统]商品ID
   商品名称: [盘点]名称 → [系统]名称
   库存数量: [盘点]实际数量 → [系统]系统数量
   ```

4. 配置规则：
   - 匹配键：`商品ID`
   - 对比字段：`库存数量`

5. 查看结果：
   - 差异：库存不符，需要调整
   - 导出差异清单，提交给财务审核

### 场景4：比较多个门店的商品价格

**背景：** 总部需要检查多个门店的商品价格是否统一。

**步骤：**

1. 上传多个文件：
   - `A门店价格.xlsx`
   - `B门店价格.xlsx`
   - `C门店价格.xlsx`

2. 创建对比组："门店价格统一性检查"

3. 列映射：
   ```
   商品ID: 全部映射到商品ID
   商品名称: 全部映射到商品名称
   零售价: 全部映射到零售价
   ```

4. 配置规则：
   - 匹配键：`商品ID`
   - 对比字段：`零售价`

5. 查看结果：
   - 差异：不同门店价格不一致的商品
   - 字段差异分布：查看哪些门店问题最多

## ❓ 常见问题

### 关于数据安全

**Q: 我的数据会被上传到服务器吗？**

A: **不会！** 所有数据处理都在您的浏览器本地完成，不会上传任何文件或数据到服务器。这意味着即使是开发者也无法看到您的数据内容。关闭浏览器后，数据会自动清除。

**Q: 我可以对比包含敏感信息的文件吗？**

A: 可以。因为所有处理都在本地，您的敏感数据完全保密。

### 关于文件格式

**Q: 支持哪些文件格式？**

A: 
- ✅ `.xlsx` (Excel 2007及以后版本)
- ✅ `.xls` (Excel 97-2003)
- ❌ `.csv` (纯文本，暂不支持)
- ❌ `.numbers` (苹果Numbers)

如果您有其他格式，请用Excel打开后另存为 `.xlsx` 格式。

**Q: 可以对比CSV文件吗？**

A: 目前不直接支持。请先用Excel打开CSV文件，然后另存为 `.xlsx` 格式再上传。

### 关于文件大小

**Q: 可以上传多大的文件？**

A: 
- **推荐大小**：单个文件小于10MB或20,000行
- **技术限制**：受浏览器内存限制，超大文件可能导致卡顿

**Q: 如果文件太大怎么办？**

A: 建议的处理方法：
1. 删除不需要对比的列
2. 删除空行和无关数据
3. 将数据按日期/类别等分成多个小文件
4. 使用8GB或更大内存的电脑

### 关于多工作表

**Q: Excel文件有多个Sheet，可以对比吗？**

A: 可以。上传后在"选择工作表"下拉菜单中选择要使用的Sheet。

**Q: 如何对比同一个文件中的两个Sheet？**

A: 您可以上传同一个文件两次，然后分别选择不同的Sheet即可。

### 关于对比结果

**Q: 为什么显示全是"缺失"，没有匹配？**

A: 这通常是因为**匹配键配置不正确**。请检查：
1. 匹配键是否正确映射
2. 匹配键的值格式是否一致（如"001"vs"1"）
3. 是否包含隐藏的空格或特殊字符

**Q: 数字"100"和文本"100"会被认为是相同的吗？**

A: 不会。Excel中数字和文本是不同的数据类型。请确保数据类型一致。

**Q: 可以保存对比配置吗？**

A: 当前版本暂不支持直接保存配置。建议将配置步骤记录下来，下次使用时快速重新配置。（此功能在开发计划中）

## 🔧 疑难解答

### 文件上传问题

**问题：无法上传文件**

可能原因和解决方法：
1. **文件格式不对**
   - 确保是 `.xlsx` 或 `.xls` 格式
   - 用Excel打开确认文件没有损坏

2. **文件有密码保护**
   - 请先在Excel中解除密码保护

3. **文件已损坏**
   - 尝试用Excel打开文件
   - 如果能打开,重新另存为新文件

4. **浏览器问题**
   - 尝试刷新页面
   - 使用Chrome、Edge等现代浏览器

### 对比结果异常

**问题：对比结果看起来不对**

检查清单：

1. **列映射是否正确**
   - 返回步骤2-3，仔细检查每个字段的映射
   - 确保"商品名称"真的映射到了正确的列

2. **匹配键是否正确**
   - 匹配键应该是唯一标识记录的字段
   - 检查匹配键的值在每个文件中是否相同格式

3. **数据格式问题**
   - 数字 vs 文本（"100" ≠ 100）
   - 日期格式是否一致
   - 有没有前导零（"001" ≠ "1"）
   - 有没有隐藏的空格

4. **Excel源文件问题**
   - 检查源文件中的数据是否正确
   - 注意合并单元格可能导致问题

**问题：缺失太多记录**

可能原因：
1. 匹配键值在不同文件中格式不同
2. 某个文件确实缺少很多数据
3. 选错了工作表

### 性能问题

**问题：浏览器变慢或卡住**

解决方法：

1. **立即处理**
   - 关闭其他浏览器标签页
   - 刷新页面重新开始

2. **优化数据**
   - 删除不需要的列
   - 缩小数据范围
   - 将大文件拆分成小文件

3. **升级环境**
   - 使用Chrome或Edge浏览器（性能最好）
   - 确保电脑有足够内存（8GB以上）
   - 关闭不必要的后台程序

**问题：无法导出报告**

可能原因和解决：
1. 浏览器阻止了下载
   - 检查浏览器下载设置
   - 允许此网站下载文件

2. 数据太大
   - 先筛选数据，只导出需要的部分
   - 删除一些不必要的列

### 显示问题

**问题：中文显示乱码**

解决方法：
1. 确保Excel文件是UTF-8编码
2. 尝试用Excel重新保存文件
3. 刷新浏览器页面

**问题：表格显示不全**

解决方法：
1. 使用表格底部的水平滚动条
2. 全屏显示浏览器窗口
3. 使用导出功能，在Excel中查看完整数据

## 💡 使用技巧

### 提高效率的技巧

1. **准备工作**
   - 对比前先在Excel中清理数据（删除空行、统一格式）
   - 确保列名清晰易懂
   - 文件名起得有意义

2. **命名规范**
   - 对比组名称要描述性强（如"2024年1月vs2月销售"）
   - 目标字段名使用通用名称

3. **分批对比**
   - 如果文件很大，考虑按时间段或类别分批对比
   - 每次对比一个主题（如只对比价格，或只对比库存）

4. **保存记录**
   - 每次对比后导出报告存档
   - 在报告中添加备注说明用途
   - 建立对比记录的文件夹

### 最佳实践

1. **数据准备**
   - 使用第一行作为列名
   - 避免合并单元格
   - 删除空行和空列
   - 确保数据类型一致

2. **选择匹配键**
   - 优先使用ID类字段
   - 确保匹配键值唯一
   - 避免使用可能重复的字段

3. **对比字段选择**
   - 只选择真正需要对比的字段
   - 不要选择太多字段以免结果混乱

4. **结果分析**
   - 先看统计仪表板了解总体情况
   - 使用筛选功能逐类查看
   - 导出报告后在Excel中深入分析

- **对比字段**：需要检查是否一致的数据列
- **对比组**：一组需要对比的文件及其配置
